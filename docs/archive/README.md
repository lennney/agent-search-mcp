# Documentation archive

Files in this directory are retained for historical traceability. They contain
completed plans, superseded proposals, and point-in-time reviews.

They are not current product documentation and must not be used to infer the
current version, supported behavior, test count, release status, or roadmap.
Use [`../index.md`](../index.md) to find the authoritative source for each
subject.

Evidence is intentionally kept outside this archive when it still supports a
reproducible benchmark, release artifact, or dated live observation.
